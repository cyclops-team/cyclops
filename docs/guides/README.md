# Cyclops user guides

Start with [Quickstart](QUICKSTART.md) if this is your first run. It installs
Cyclops, opens the full workspace, and walks through a two-agent review
handoff. The remaining guides answer one operational question each.

## Start and operate Cyclops

| Guide | Use it when... |
|---|---|
| [Quickstart](QUICKSTART.md) | You want the shortest path from install to a claimed message and reply. |
| [Install, update, and remove](install.md) | You need installation paths, rollback, update, or uninstall details. |
| [Troubleshooting](troubleshooting.md) | A daemon, pane, notification, or receipt is not behaving as expected. |

## Message another agent

| Guide | Use it when... |
|---|---|
| [Send, wake, claim, and reply](send.md) | You need the durable messaging contract and recovery behavior. |
| [History](history.md) | You want to page through and inspect the durable record. |
| [Wait](wait.md) | You need to understand what observed pane state does and does not prove. |

## Use the interfaces

| Guide | Use it when... |
|---|---|
| [Workspace UI](workspace-ui.md) | You want the full-screen workspace, keyboard, mouse, tabs, and Messages pane. |
| [Watch UI](ui.md) | You want the standalone Stream and Messages monitor. |
| [Workspaces](workspaces.md) | You are creating, saving, restoring, or starting layouts. |
| [Panes](panes.md) | You are naming panes or reasoning about stable pane identity. |
| [Sizing](sizing.md) | You need to know which client may resize a shared tmux session. |
| [Themes](themes.md) | You are selecting or authoring semantic colors. |

For wire formats, vendor integration, and measured performance claims, use the
[technical reference](../reference/README.md). Contributors should begin with
the [engineering map](../development/HANDOFF.md).
