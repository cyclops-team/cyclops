---
title: "Attach to tmux"
description: "Connect Cyclops to tmux sessions, windows, and panes."
---

Cyclops attaches to tmux by target. A target can be a session, a window, or a single pane.

## Attach to a session

Register every pane in a session as an agent:

```bash
cyclops attach work
```

New panes opened later are picked up automatically as long as Cyclops is running.

## Attach to a specific window

```bash
cyclops attach work:agents
```

Only panes inside the `agents` window are tracked.

## Attach to a single pane

```bash
cyclops attach work:agents.1
```

Use this when you only want Cyclops managing one agent in an otherwise busy session.

## Name your agents

Give an agent a friendly name at attach time:

```bash
cyclops attach work:agents.1 --name reviewer
```

You can then refer to it by name:

```bash
cyclops send reviewer "Review the diff on origin/main."
```

## Detach without stopping agents

```bash
cyclops detach
```

tmux keeps running, so your agents keep their state.

## Troubleshooting

- Run `tmux ls` to confirm the target session exists.
- If Cyclops cannot see a pane, make sure it is inside the session you attached to.
- Cyclops requires tmux 3.2\+. Check with `tmux -V`.
