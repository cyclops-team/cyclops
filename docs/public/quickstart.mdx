## 1. Install Cyclops

```bash
curl -fsSL https://www.usecyclops.dev/install.sh | sh
```

The installer needs tmux 3.2 or newer, curl, Git, and a Rust toolchain. If it
adds a PATH block, open a new shell or run the reload command it prints.

## 2. Open the default workspace

```bash
cyclops start
```

The first run creates a `main` tmux session from the one-pane `solo` preset,
starts `cyclopsd`, and writes the initial config, themes, and detection
manifests.

## 3. Start an agent

Attach to the session and run the coding-agent CLI normally:

```bash
tmux attach -t main
```

The default pane is named `implementer`. Start Claude Code, Codex CLI, Cursor
Agent, or another CLI for which you have a detection manifest.

## 4. Check the roster

From another terminal:

```bash
cyclops list
cyclops status
```

If you created an extra pane yourself, name it by tmux pane id:

```bash
cyclops name %1 reviewer
```

## 5. Send a message

```bash
cyclops send implementer --subject "Summarize the README" --body "Call out the setup steps and test commands."
```

The receipt says whether the agent's own hook verified the delivery or
Cyclops confirmed it from screen evidence. Messages and their final delivery
states remain available through `cyclops history`.

## 6. Watch the work

```bash
cyclops watch
```

`cyclops watch` opens the live event stream. A bare `cyclops` opens the
full-screen workspace with the sidebar, tabs, and live pane canvases.
