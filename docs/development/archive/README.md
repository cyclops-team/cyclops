# Archived development records

This directory holds revision-bound historical records: completed audits,
superseded charters, and design reviews tied to a specific commit or
milestone. None of them govern current behavior. Where one differs from the
current code or from the current behavior contracts (`ARCHITECTURE.md`,
`INVARIANTS.md`, `DELIVERY.md`, `docs/reference/PROTOCOL.md`), the current
code and those contracts win.
